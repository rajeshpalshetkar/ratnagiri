# Ratnagiri Android App

Android project source for the Ratnagiri Blogger-based news and information app.

## Build configuration

- `compileSdk`: 36
- `targetSdk`: 36 (Android 16)
- `minSdk`: 23
- `versionCode`: 12
- `versionName`: 4.0.1

The GitHub Actions workflow builds:
- Debug APK for installation/testing
- Release Android App Bundle (AAB), currently unsigned

## Google Play upload

The AAB generated by this workflow is unsigned. To upload it to Google Play, it must be signed with the app's existing upload key. Do not generate a replacement key if the app already has a Play Console upload key.

## Remote app configuration

The app's `Config.java` points to the Google Drive configuration file ID supplied for this app. Keep the full production JSON hosted at that Drive location. Do not commit API keys or private signing credentials to this repository.

The checked-in `config_json/config.json` is a sample/template and contains placeholder Blogger credentials; it is not a replacement for the live remote configuration.

## Build locally

Open `android_studio/BloggerNewsApp` in Android Studio, or run:

```bash
./gradlew :app:assembleDebug :app:bundleRelease
```
